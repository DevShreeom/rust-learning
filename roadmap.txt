1-YEAR PLAN: RUST + BACKEND + SECURITY

TIME BUDGET
- Months 1-6: 30-60 min/day, since studies come first
- After your exams: ramp up to 2-3 hrs/day
- If a phase runs late, extend it. Don't skip ahead.

RULES
- Rust is the main. No language switching.
- One project per phase, on GitHub, with a README.
- Never write your own crypto. Use well-reviewed crates.
- DSA/LeetCode: 2-3 problems/week in Rust, starting month 3.
- Type every example yourself. Never copy-paste from the book.

PHASE 1 (Months 1-3): RUST FUNDAMENTALS
Resources: The Rust Book chapters 1-12 (ends with the minigrep project),
  Rustlings, The Linux Command Line (free)
Also: Git basics, comfort in the terminal
Project 1: minigrep from chapter 12, then your own CLI tool that solves a real problem for you
(Status: currently on chapter 3)

PHASE 2 (Months 4-6): FINISH THE BOOK + SQLITE + NETWORKING
Resources: The Rust Book chapter 13 to the end
  (closures, iterators, smart pointers, concurrency, async, patterns, advanced features, final web server project)
  SQL basics + SQLite docs, "Use The Index, Luke" (free, indexes)
  Networking: HTTP, TCP/IP, DNS, TLS at a conceptual level (Computer Networking: A Top-Down Approach, early chapters)
Project 2: SQLite-backed CLI app (notes or expense tracker) using rusqlite
Project 3: TCP port scanner using std::net (then async later)

CHECKPOINT (Month 6): Can you write a medium Rust program without copying? If not, repeat Phase 2.

PHASE 3 (Months 7-9): BACKEND WITH RUST
Resources: Tokio tutorial (free), axum docs, serde, sqlx
  Zero To Production In Rust (paid book, backend from scratch)
Skills: async Rust, REST design, JSON, error handling in services, logging, tests
Project 4: REST API with axum + SQLite: users, login, password hashing (argon2), tests
Also: Docker basics (containerize Project 4)

PHASE 4 (Months 10-12): POSTGRESQL + SECURITY
Resources: PostgreSQL tutorial, OWASP Top 10, OverTheWire Bandit (free wargames)
  Black Hat Rust (security tooling in Rust, optional)
Skills: move Project 4 to PostgreSQL, migrations, TLS, auth tokens, input validation, common web vulnerabilities and how to prevent them
Project 5 (capstone): secure backend service OR encrypted password-manager CLI, deployed, with threat model in README
Also: one small contribution to an open-source Rust project

LATER (year 2+)
Embedded Rust Book, Embassy, a Raspberry Pi Pico or ESP32, C and DSA from college

NOTES FILE
Keep a running file of what you got stuck on and how you solved it.
